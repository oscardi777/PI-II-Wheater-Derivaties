=====================================

IMPORTANTE:

Este NO será un VAR de cuatro variables.

El modelo será un VARX.

La estructura debe ser:

RONI

* Precio
* Generacion

Por tanto:

Y_t = [Aportes_t, Precio_t, Generacion_t]'

Y_t = vector de variables endógenas.

X_t = variable exógena RONI.

c = vector de constantes.

A_i = matrices de coeficientes autorregresivos.

B = matriz de coeficientes asociados a RONI.

ε_t = vector de innovaciones.
